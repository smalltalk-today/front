# 카드 화면

| 경로             | 화면                                                                    |
| ---------------- | ----------------------------------------------------------------------- |
| `/card`          | 카테고리별 예제 카드, 대화 소재 랭킹, 요약·복사·저장·문장 재생성        |
| `/card/saved`    | 저장 목록과 카테고리 필터, 저장 해제, 빈 상태                           |
| `/card/[id]`     | 저장 당시 문장을 보여주는 상세 화면. 유효하지 않은 ID에는 404 화면 표시 |
| `/card/settings` | 저장 목록 전체 삭제, 앱 버전, 정책 링크 상태                            |

768px 미만에는 하단 탐색을 표시합니다. 768px 이상에는 상단 탐색을 표시합니다. 1280px 미만에는 랭킹 탭을, 1280px 이상에는 피드 우측 랭킹을 표시합니다.

카드는 최대 50개까지 메모리에 저장됩니다. 앱 안에서 화면을 이동하면 유지되고 새로고침하면 초기화됩니다. 문장은 이슈마다 최대 3회 재생성할 수 있습니다. 설정에서 삭제를 확정하면 저장 목록을 비우며 문장 재생성 상태는 유지합니다. 정책 링크는 실제 주소가 정해지면 연결합니다.
